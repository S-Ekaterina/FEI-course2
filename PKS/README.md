&nbsp;&nbsp;Computer and Communication Networks was easily one of the most challenging courses I have taken. The workload was intense, requiring us to complete weekly tests and assignments while maintaining at least a 50% passing threshold to stay on track. This consistent pressure forced me to build strong study habits.

&nbsp;&nbsp;As the culmination of the course, I built a custom Python application designed to run on two separate devices and establish a reliable communication link. The program handles two-way transmission by constantly sending and receiving data packets, while maintaining a background ping system to continuously verify that the connected peer is online. To transfer large files without overloading the connection, the software fragments the payload into sequential chunks and transmits them one by one. It verifies successful delivery by waiting for acknowledgment signals from the receiver and includes an automated error-handling strategy to retry transmissions if any data packets are lost or corrupted along the way.

&nbsp;&nbsp;Overall, this project gave me solid, hands-on experience in socket programming and network protocol design.
