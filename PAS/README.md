# Probability and statistics

> [!TIP]
> The probability of me actually using the R language in my daily work is probably around 20-30%, but the analytical mindset itself is definitely a solid bonus!

&nbsp;&nbsp;The Probability and Statistics course was a genuinely fascinating journey that introduced us to statistical computing through the R programming language. Getting used to R initially was quite a challenge, as it demands absolute precision - a single misplaced symbol or syntax mistake can completely throw off your results. To build a solid foundation, we started by calculating probabilities manually by hand to truly grasp the underlying mechanics before handing the workload over to the computer.

&nbsp;&nbsp;Once we mastered the core concepts, we transitioned to writing code and saw the real magic happen. It was eye-opening to realize that just a few lines of R script could effortlessly solve complex calculations that previously took pages of manual work. However, achieving that meant carefully dissecting every single word, variable, and symbol in the code to understand precisely what was happening under the hood.

&nbsp;&nbsp;Ultimately, this course was an incredible exercise in analytical rigor. Bridging the gap between manual math and programmatic execution didn't just teach us a new tool - it gave us a deep, practical appreciation for speaking the true languages of mathematics and statistics.
