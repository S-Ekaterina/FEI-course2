# Database systems

> [!TIP]
>It turned out to be an awesome game, but it's impossible to show it to anyone who isn't into databases :(

&nbsp;&nbsp;This was easily one of my absolute favorite courses. We started with the fundamentals of SQL queries and then spent the semester working on a comprehensive, three-part project. The assignment was to design and implement a database for a PvP game. I chose Cyberpunk as my theme and built the entire system around its lore.

&nbsp;&nbsp;I designed the schema and created tables for everything: characters, classes, class bonuses, weapons, armor, attacks, inventories, battles, and combat logs. I absolutely loved the entire conceptual process and the logic calculations behind it.

&nbsp;&nbsp;The final part of the project was about bringing it all to life. First, I initialized all the tables. Then, I wrote database functions and procedures to handle real-time player interactions with the environment—such as executing an attack, looting items, healing, and dynamically calculating remaining HP. To make debugging easier, I added a visualization layer to track the database state and see the results in real-time. Finally, I covered everything with robust test cases. I also implemented a List of Created Indexes (Zoznam vytvorených indexov) to significantly optimize performance and speed up queries for frequently accessed data.
