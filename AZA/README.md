# Analysis and complexity of algorithms

> [!TIP]
>

&nbsp;&nbsp;This course felt a bit like a continuation of DSA, but with a completely different shift in perspective. While our previous goal in DSA was simply to write correct and fast code, here the main focus was on minimizing memory consumption (Space Complexity).We built various programs, calculated exactly how many system resources and computing power they consumed, and then worked on optimizing the existing code to make it as lightweight as possible. Throughout the semester, I discovered a wide variety of advanced optimization techniques and foundational algorithms that remain highly relevant and widely used in the tech industry today.
